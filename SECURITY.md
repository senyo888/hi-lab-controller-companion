# Security policy

## Supported version

Security fixes are applied to the current published companion release.

## Reporting

Use GitHub private vulnerability reporting when available. Do not include shared
secrets, tokens, private addresses, target identities, mailbox contents, signed status
documents, or operational evidence in a public issue.

Public issues may report nonsensitive reproduction steps and affected release numbers.
If private reporting is unavailable, open a minimal public issue requesting a private
maintainer contact channel without including sensitive details.

## Boundary

This repository contains only the Home Assistant companion. External controller
credentials, target configuration, deployment evidence, and private runtime state are
out of scope and must not be copied here.
